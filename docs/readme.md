# Resumes & Candidate Documents Directory

Place your candidate resume files here:
- **PDF format:** e.g., `resume.pdf`
- **DOCX format:** e.g., `resume.docx`

> [!NOTE]
> All `.pdf` and `.docx` files in this directory are automatically ignored by `.gitignore` (rules `*.pdf` and `*.docx`), ensuring actual sensitive resume data will **not** be uploaded or pushed to GitHub.
